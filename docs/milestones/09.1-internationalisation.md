# Milestone 09.1 — Internationalisation (English + German)

## Outcome

netrics speaks English (default) and German. Each user picks a language
under Account; screens (browser kiosk, Apple TV) follow the workspace's
screen language; self-hosters set an instance default. The web app, the
emails, tile labels and connector metadata are translated; numbers and
dates follow the language.

Design: [ADR 0016](../decisions/0016-internationalisation.md). Umbrella:
#162. GitHub milestone "i18n (English + German)".

## Dependencies

- Milestone 09 (Dashboard Studio), whose screens and labels this
  translates. Runs alongside 10 and later milestones: it is cross-cutting,
  not a product step after 09.

## In scope

- Typed message catalogs (ICU subset) for the web app, emails and the
  shared domain words; no locale in app URLs
- `users.locale`, `workspaces.screen_locale` (migration 0036),
  `NETRICS_DEFAULT_LOCALE`
- English and German for every web screen, email, payload label and the
  tvOS app's own text (String Catalog)
- Optional `translations` in connector manifests (SDK 0.2.6)
- A lint rule against hard-coded UI strings and a catalog parity test

## Out of scope

- Languages beyond English and German (the mechanism allows them)
- Regional formats (`de-CH`, `en-GB`) as separate choices
- The marketing site's `/en` and `/de` (private repository)
- Translating data users write (dashboard names, widget titles, text
  widgets)

## Issues

2. #251 — Web: auth and onboarding
3. #252 — Web: workspace, connections and devices
4. #253 — Web: dashboards and Studio, locale-aware formatting
5. #254 — Web: settings, admin and API error messages
6. #255 — Emails in the recipient's language
7. #256 — Screens: device payload labels, kiosk and tvOS
8. #257 — Connector translations (SDK 0.2.6)

2–8 depend only on 1 (7 uses 8 for metric names, and falls back to English
without it). The lint rule covers all of `apps/web/src` after 2–5.

## Exit gate

Switching an account to Deutsch translates every web screen; a workspace
with screen language Deutsch shows German labels, chrome and numbers on
the kiosk and the Apple TV; password reset and invitation emails arrive in
the recipient's language; `NETRICS_DEFAULT_LOCALE=de` makes a fresh
self-hosted install German; the lint rule and parity test pass.
