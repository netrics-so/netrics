# Milestone 09.3 — Signal design

## Outcome

netrics looks finished and is easy to find your way around. The admin is
light and warm, with one teal accent, self-hosted type and a sidebar that
shows the whole product; every area has its own page. TV dashboards get
layered surfaces, show how fresh every number is, and come alive when a
slide enters, without breaking the readability rules or Reduce Motion.

Design: [ADR 0018](../decisions/0018-signal-design.md), from the owner's
"Signal" handoff (2026-10-04). GitHub milestone "09.3 Signal design".

## Dependencies

- Milestone 09 (Dashboard Studio) and 09.2 (screen formats): the renderer,
  Studio and formats this restyles.
- Milestone 09.1 (internationalisation): every new string in English and
  German.

## In scope

- Admin tokens, self-hosted fonts and restyled primitives
- App shell: full-sitemap sidebar, top bar, area routes, Studio icon rail,
  phone drawer
- Screens, Dashboards and Sources pages; Studio chrome; pairing screen with
  a real QR code; sign-in pages and first-run onboarding
- TV: layered surfaces derived from the theme, freshness footers, refresh
  countdown, slide footer, tabular figures, netrics Dark chart colours,
  enter motion and continuous cues, data-state surfaces, tvOS parity

## Out of scope

- Playlists, schedules, alerts, global search, map view of screens
- Google and passkey sign-in
- Changes to grid geometry or the shared type scale

## Security invariants

- No new data leaves the workspace: list API additions for thumbnails and
  "shown on" counts are workspace-scoped with RLS and explicit
  `workspace_id` predicates, with cross-workspace tests.
- Fonts and the QR code are local; the CSP stays `font-src 'self'` and no
  page loads third-party assets.
- The QR code encodes only the approval URL the pairing screen already
  shows.

## Verification

- Every admin page in the new palette at desktop and 320 px width, keyboard
  navigable, text contrast at least 4.5.
- Existing dashboards look the same in layout on every format and client;
  only surfaces, colours of netrics Dark charts and the new footers change.
- No TV text below the ADR 0015 §8 minimums; `fits` stays conservative with
  IBM Plex Sans.
- With `prefers-reduced-motion` and tvOS Reduce Motion nothing animates;
  without it, motion stops after the enter except pulse, blink and sweep.

## Exit gate

In production, a non-technical user signs in, connects a source, builds a
dashboard and shows it on a screen using only the sidebar; the Overview
dashboard runs on a physical Apple TV and a browser kiosk with the polished
widgets and enter motion, and without motion under Reduce Motion (#314).
