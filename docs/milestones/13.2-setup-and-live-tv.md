# Milestone 13.2 — Quick setup and live TV

## Outcome

Adding a product to the dashboard takes a few steps instead of many, and a
change made in the web app reaches every paired TV within seconds instead
of at the next poll.

GitHub milestone "13.2 Quick setup and live TV".

## Dependencies

- Milestone 13.1: the Developer Portfolio template is the second template
  that must be quick to set up and update.

## In scope

- #783: updating a store template and linking apps to projects and
  websites takes far too many manual steps
- #789: the TV applies dashboard changes in near real time
- #879: adding a product to the Developer Portfolio links its resources
  across connections in one flow

## Out of scope

- Alerts (milestone 14)
- The slide design pass, which the owner opens separately

## Issues

| Issue | What                                           |
| ----- | ---------------------------------------------- |
| #783  | Store template: fewer manual steps             |
| #789  | TV: apply dashboard changes in near real time  |
| #879  | Developer Portfolio: add a product in one flow |

## Exit gate

The owner adds a new product (an app with its website, Railway service and
PostHog project) to both templates in one short flow, and an edit in Studio
shows on the Apple TV within a few seconds.
