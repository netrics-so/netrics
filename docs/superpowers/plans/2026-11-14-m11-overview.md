## Cross-plan contracts

- **Errors:** `DataProcessingError(code, fieldId?, nodeId?)`; API body
  `{ error, fieldId?, nodeId? }` (S-G4). VB's `ExpressionEditor` takes
  `problem?: { code, fieldId? }`; the step list (S-G5) passes `nodeId`
  placement. Both S and VB edit `data-errors.ts` — later PR rebases.
- **Undo:** one helper, `edit-history.ts` (S-G6). VB-G3 uses it for the model
  editor's builder state.
- **Impact:** `apps/server/src/data/impact.ts` —
  `loadImpactGraph(tx, workspaceId)`, `collectDataImpact(graph, target)`;
  response includes `changedMeasureIds` and `pinnedVersion`. TU-E may show it
  in the update review.
- **Archiving:** projects get `archived_at` (IP-B); dashboards get
  `archived_at` (TU-D), set only by the template copy swap. IP-C's dashboard
  lists and pickers must hide archived dashboards once TU-D lands (TU-D adds
  that filter if IP-C merged first).
- **Migrations:** 0071 (IP-B), 0072 and 0073 (TU-A, TU-D). Whoever merges
  later renumbers if main moved.
